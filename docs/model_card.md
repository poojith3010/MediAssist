# Experimental model card

The risk workflow uses scikit-learn's built-in Wisconsin breast cancer teaching dataset, a legally accessible educational dataset bundled by scikit-learn. The target and evaluation metrics are generated by `app.train_model`; no metrics are hard-coded.

This model is for software demonstration only. It is not clinically validated, should not be used for patient care, and may encode dataset bias. SHAP values explain model behavior and do not establish causality.
